Tesla Motors - Sistema de Gestión de Concesionario
Descripción

Tesla Motors es un sistema de gestión desarrollado en Java para administrar las diferentes operaciones de una tienda y concesionario de vehículos Tesla.
El sistema cuenta con diferentes niveles de acceso dependiendo del tipo de usuario que ingrese. De esta manera, las funcionalidades disponibles se adaptan a las responsabilidades de cada usuario dentro de la empresa.
El proyecto busca simular la gestión de un concesionario, permitiendo administrar vehículos, ventas, clientes, empleados, pagos, piezas y diferentes procesos relacionados con la operación de la tienda.

Tipos de usuario

El sistema cuenta principalmente con dos tipos de usuarios:

Empleado

Los empleados tendrán acceso a las funciones necesarias para realizar y consultar las operaciones habituales de la tienda.

Entre sus funcionalidades se encuentran:

Consultar el catálogo de vehículos.
Consultar información de clientes.
Consultar ventas.
Registrar nuevas ventas.
Cancelar ventas en espera.
Consultar vehículos en espera.
Comprobar pagos.
Consultar información de los vehículos disponibles.

Administrativo

El usuario administrativo tendrá acceso a todas las funcionalidades disponibles para los empleados y, adicionalmente, contará con herramientas para administrar diferentes aspectos internos del concesionario.

Además de las funciones del empleado, podrá:

Gestionar empleados.
Consultar y gestionar clientes premium.
Consultar vehículos agotados.
Consultar vehículos pendientes por surtir.
Gestionar piezas y repuestos.
Administrar información relacionada con el inventario.
Consultar información general del concesionario.

Funcionalidades principales
Catálogo de vehículos

Permite consultar los vehículos Tesla disponibles en el concesionario.

Se podrá visualizar información como:

Modelo.
Precio.
Color.
Año.
Disponibilidad.
Características del vehículo.
Estado del vehículo.

Gestión de ventas

El sistema permitirá gestionar las ventas realizadas en el concesionario.

Entre las operaciones disponibles estarán:

Agregar una venta.
Consultar ventas.
Consultar ventas en espera.
Cancelar una venta en espera.
Comprobar el estado de un pago.
Consultar información relacionada con una venta.

Gestión de clientes

Permite almacenar y consultar información de los clientes del concesionario.

El sistema podrá diferenciar entre clientes normales y clientes premium, permitiendo que los usuarios administrativos tengan acceso a información adicional sobre estos últimos.
